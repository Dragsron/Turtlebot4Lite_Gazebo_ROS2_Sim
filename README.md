# Turtlebot4Lite_Gazebo_ROS2_Sim
https://github.com/turtlebot/turtlebot4, meshes based on turtlebot4 github. In this repository package for simulating turtlebot4 lite using ROS2, RVIZ2, and Gazebo. Put the package to the src folder of your ROS workspace. Colcon build and source install to launch robot_nav2_launch.py
